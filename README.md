# HID 커널 퍼징 커버리지 탐색기

성균관대 정보시각화 기말 프로젝트. syzkaller 로 Linux HID 드라이버를 퍼징한
캠페인의 함수 단위 커버리지를 세 개의 연동된 뷰로 탐색한다.

- **A 드라이버 궤적** — 캠페인이 아직 움직이는가 (드라이버별 획득 스파크라인)
- **B 호출 그래프** — 커버된 코드가 어디서 멈추는가 (`vmlinux` 직접 호출 엣지)
- **C 계측 이득** — 지연 실행 계측을 더 붙일 값이 있는 곳은 어디인가

데이터: 함수 2,883개 / 드라이버 225개, QEMU x86_64, 커널 `7.2.0`, KASAN.

결함 ID 열에는 **상류(linux-input)에 실제로 발송해 lore.kernel.org 에 공개
스레드가 있는 건만** 실었다. 미발송 건의 ID·상세·재현자는 포함하지 않는다.
